## 기능유형 목록 (FT·SP)

> 화면 또는 기능의 UX 유형을 구분합니다. 프로젝트마다 공통으로 사용 가능합니다.

| 기능유형 | 설명 |
|---------|------|
| 리스트 조회 | 목록 검색 및 필터링 화면 |
| 상세 조회 | 단건 상세 보기 화면 |
| 신청/등록 | 사용자가 데이터를 생성·제출하는 흐름 |
| 결재/승인 | 결재선 기반 승인·반려 처리 |
| 기준관리 | 운영 기준 데이터(마스터) 등록·수정·삭제 |
| 메일송신 | 이벤트 기반 이메일 자동 발송 |
| 엑셀 다운로드 | 조회 데이터 엑셀 출력 |
| 권한/접근제어 | 역할별 메뉴·기능 접근 제어 |
